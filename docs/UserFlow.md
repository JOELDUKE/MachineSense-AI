# User Flow

## Overview

The user flow illustrates how a factory owner interacts with the MachineSense AI system. From logging into the dashboard to receiving AI-powered maintenance recommendations, the workflow is designed to provide a simple and intuitive monitoring experience while enabling proactive maintenance decisions.

## Workflow

1. **Factory Owner Login**

   The factory owner logs into the Smart Factory Dashboard to access machine monitoring and analytics.

2. **Dashboard Loading**

   The dashboard displays an overview of all connected machines, including their health status and recent alerts.

3. **Machine Selection**

   The user selects a specific machine to monitor its real-time performance.

4. **Live Data Monitoring**

   Live sensor data, including temperature, vibration, and power consumption, is displayed on the dashboard.

5. **AI Analysis**

   The AI Prediction Engine analyzes the sensor data, detects anomalies, estimates failure probability, and generates maintenance recommendations.

6. **Alerts and Notifications**

   If a potential issue is detected, the system generates maintenance alerts for the user.

7. **Maintenance Action**

   Based on the AI recommendations, preventive maintenance is performed to avoid unexpected machine failures.
